# 2026-06-24 核心功能收口复查

## 结论

本轮继续按“只保留核心商品、分类、订单、支付、用户中心、基础装修/跳转能力”的目标收口。旧活动、优惠券、直播、积分商城、抽奖、赠礼、发票入口已从后台菜单合同、装修默认配置、链接选择器、小程序页面配置、核心跳转链路和确认无引用的前端孤儿文件中清理。

真实后台菜单合同仍需要外部提供 `ADMIN_MENU_URL` 和 `ADMIN_TOKEN`。当前本机环境未设置这两个变量，因此合同脚本按规则跳过运行时菜单请求；token 未写入仓库，也未写入本文档。

## 本轮清理

- 后台链接选择器 `template/admin/src/components/linkaddress/index.vue` 已收口为核心链接选择，只保留普通链接、商品、商品分类、自定义链接，并用黑名单过滤旧小程序链接。
- 后台移动装修组件注册由全目录扫描改为显式白名单，旧活动、优惠券、直播、积分商城、预售、榜单、短视频等装修组件不再进入构建注册表。
- 后台装修默认模板中的旧链接已替换为商品列表、首页或用户中心等核心链接。
- 小程序核心链路中的旧跳转已改回普通商品详情、订单详情、支付状态或用户中心。
- 已删除确认不再注册、无 import/require、无构建配置引用的前端孤儿页面和静态资源，包括小程序旧活动、积分商城、抽奖、赠礼、发票、专题、旧后台核销页，以及后台旧装修组件和积分订单 Vuex 模块。
- 已删除小程序旧活动/抽奖/积分商城 API 包装，`sharePoster` 不再依赖旧活动接口。
- 后台优惠券选择器保留组件壳用于兼容商品页挂载，但不再拉取退役优惠券接口，打开后返回空列表。
- 小程序订单 API 已保留购物车、订单、退款、收银台等核心接口，仅移除退役的发票下载和领取礼物接口。
