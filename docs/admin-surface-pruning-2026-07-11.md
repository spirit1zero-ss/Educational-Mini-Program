# 管理后台退休模块物理精简 - 2026-07-11

## 结果

- 管理后台源码从 845 个文件、约 30.3 MB，降至 305 个文件、约 2.12 MB。
- 整个项目从本轮开始前的 205.2 MB 降至 177.03 MB。
- 排除 PHP `vendor` 与现有 `public/admin` 编译包后，源码口径为 1,707 个文件、43.75 MB。

## 保留范围

- 后台登录与主页。
- 用户、会员等级、付费会员、卡密会员、会员权益与会员协议。
- 分销、财务、用户统计、余额统计。
- 管理员、角色、权限、系统配置、组合数据、定时任务与必要运维页面。
- 图片上传和会员协议富文本编辑器；视频上传入口已移除。

## 删除范围

- 商品、商城订单、退款、营销、积分、签到和事业部页面。
- 页面装修、旧移动商城配置、商品选择和热点装修组件。
- CRUD、代码生成、数据字典、在线升级、跨版本升级和文件管理页面。
- 视频上传组件及其全局插件。
- 商品、营销、CMS、客服、抽奖和 CRUD 前端 API 文件。
- 两套未使用 Emoji 雪碧图、未引用旧商城图片和本地图标生成稿。
- 已无调用方的 Vuex 模块和路由模块。

## 依赖调整

以下只服务于已删除模块的依赖已从入口和 `package.json` 移除：

- `awe-dnd`
- `emoji-awesome`
- `tree-table-vue`
- `v-org-tree`
- `vue-codemirror`

`package-lock.json` 的根依赖清单已与 `package.json` 对齐。由于当前机器离线缓存缺少 Webpack 元数据，未执行完整依赖重解析；部署安装依赖时应重新生成干净锁文件。

## 部署提醒

当前 `crmeb/public/admin` 仍是原来的编译产物，因此线上后台行为暂未改变。部署前需要在 `template/admin` 安装依赖并重新构建，再用新构建结果替换 `crmeb/public/admin`。构建后还需要人工检查登录、用户、会员、分销、财务、权限和系统配置页面。
