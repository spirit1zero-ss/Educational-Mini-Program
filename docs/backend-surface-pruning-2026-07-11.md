# 后端退役模块精简 - 2026-07-11

## 结果

- 项目从 177.03 MB 降至 176.03 MB。
- `crmeb/app/adminapi` 从约 120 个 PHP 文件降至 91 个，当前约 0.44 MB。
- 本轮净删除 29 个后台 PHP 文件，并收缩应用与导出入口。

## 已物理删除

- 商品管理、商城订单、退款、积分与签到的后台路由和专用控制器。
- 商品、订单、交易三类统计路由和控制器。
- 旧 CRUD 自动路由入口与空的 widget 路由。
- 公众号内容、渠道码、小程序 CI、外链管理等已退役应用控制器。
- 在线升级控制器、升级客户端控制器和仅为商城链路服务的后台中间件。

## 已收缩但继续保留

- `app.php` 只保留公众号模板消息与小程序订阅消息同步接口。
- `export.php` 和 `ExportExcel.php` 只保留用户、会员卡、分销员、资金和佣金导出。
- 用户统计、余额统计和资金流水继续保留。
- 图片上传与图片素材选择继续保留，未随服务器文件管理功能删除。

## 明确保留的业务链路

- 分销员管理、分销申请、上下级推广关系和分销等级。
- 佣金记录、佣金导出和提现相关财务功能。
- 小程序邀请海报、邀请记录与分销收益接口。
- 付费会员、训练营会员订单和支付回调。
- 用户、权限、系统配置、消息通知与必要运维入口。

## 验证

- `tests/miniprogram-smoke.mjs`：通过。
- `tests/admin-retired-surface.contract.mjs`：通过。
- `tests/backend-retired-surface.contract.mjs`：通过；检查退役后端不会回归、核心分销文件存在、保留接口存在，以及后台 PHP 本地类导入没有缺失。
- 残留扫描未发现已删除商品、订单、营销控制器或 `ProductChainMiddleware` 的后台引用。

当前环境没有 PHP CLI，因此本轮无法执行 `php -l`。部署环境安装 PHP 后，应对 `crmeb/app` 运行全量语法检查，并进行登录、用户、分销、佣金、会员订单、支付回调和图片上传的接口冒烟测试。

## 下一阶段建议

`services/activity`、传统商城订单服务和商品服务仍占据较多源码，但它们被旧的用户服务、支付回调、监听器和定时任务交叉引用。下一阶段应先拆除这些保留类中的商城耦合，再删除服务、DAO、模型、任务和监听器，不能直接整目录删除。
