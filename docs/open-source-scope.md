# 教育系统公开范围与发布前检查

核对日期：2026-09-17。当前工作为开源准备，不是新的公开发布或许可证授予。

## 可以准备公开的内容

- 具有明确授权的项目源码、模块说明、脱敏配置示例、测试和必要的构建文件。
- 项目介绍、贡献方式、安全报告渠道和第三方来源说明。
- 自有增量功能与上游代码分别说明，采用量仅使用可核实的数据。

## 排除内容

- 真实 `.env`、密码、AppSecret、支付密钥、Token、私钥和证书私钥。
- 数据库备份、Redis 数据、用户上传文件、生产日志、订单和用户数据。
- 内部聊天摘录、客户交付件、商业合同与未获授权的课件、图像或字体。
- 本机工具缓存、依赖目录、恢复快照、未经审查的压缩包及构建产物。

`.gitignore` 只是防止未来误加入；已经跟踪的文件和历史提交仍需独立检查。

## 当前待完成项

1. CRMEB 上层 Apache 许可与服务端附加许可的适用范围，见第三方声明。
2. 历史 uni-app 示例配置包含与上游相同的 AppSecret 字面量。不能据此认定为本项目生产凭证，也不应当作可用密钥。新公开版本不携带该示例；历史处理需单独核对。
3. 安装 SQL 不只是建表语句。已对照公开 CRMEB master：管理员、用户、系统配置、附件和客服五类 INSERT 与上游逐字一致，目前没有证据表明这些记录是本项目生产数据；这不代表所有其他种子及业务素材均已完成审查。独立部署仍需更换初始账号与配置，正式分发前按最终范围复核种子内容。
4. 业务素材与客户资料的授权、默认分支和实际维护分支一致性。

尚未宣称通过全量安全审计或满足 Codex for Open Source 的录取标准。此阶段不改写历史、不变更仓库可见性，也不执行生产凭证轮换。
