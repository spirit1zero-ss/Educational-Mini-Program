## 数据库导入

对于已经上线训练营、会员、报名表功能的现有数据库，本轮只执行：

`src/CRMEB/CRMEB-master/crmeb/database/patches/2026-09-15-redemption-update.sql`

该文件已合并并替代此前的 `2026-09-14-admin-local-data-repair.sql`，不用另找旧文件重复导入。不是新建系统的安装脚本。

1. 备份目标数据库，在管理工具中选择实际业务数据库。
2. 确认表前缀是 `eb_`；若正式库使用其他前缀，应修改脚本中的表名及元数据查询后执行。
3. 以 UTF-8 导入上述增量 SQL。它会按需补齐批次兑换截止字段、统一订单号排序规则、开启现有会员兑换开关、显示卡密/会员记录菜单、修正两条报名菜单名称。
4. 查看 SQL 最后的核对结果：会员开关为 1，卡密/会员记录菜单显示，订单号排序规则为 utf8mb4_general_ci。
5. 同步本次后端、小程序和已编译后台文件；按现有部署流程刷新应用配置缓存并重启后端，后台重新登录获取最新菜单。小程序重新编译后上传。

本轮不导入整库 `database/install/crmeb.sql`，不导入本地账号、兑换码、订单、报名记录。SQL 不开通任何用户会员、不生成兑换码。正式库未连接，以上按当前项目既有业务结构编制；若正式库尚缺会员、训练营或报名表基础表，应先核对原版本的迁移记录，不能用整库覆盖现有数据。

## 本轮功能

- 我的页恢复兑换码，沿用微信身份登录，后台生成的有效卡号可开通永久会员。
- 后台“用户 → 付费会员 → 卡密会员 → 添加兑换码”，支持查看、导出、冻结/激活及使用记录；修复改批次名误改卡片状态和备注未保存。
- 兑换成功后提示去填写孩子信息与联系电话；“我的 → 会员登记表”对会员持续开放，可补填和修改。报名联系电话与个人资料手机号独立保存。
- 恢复卡密与会员记录菜单，刷新页面时同步最新菜单，避免旧缓存乱码。
- 页面分享、专属海报文案、客服电话和小圆形在线客服按此前确认保留。
