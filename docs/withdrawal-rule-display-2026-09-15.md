# 提现规则展示补充（2026-09-15）

## 依据和运营时限

微信审核反馈要求在提现页面清晰展示可提现额度、每日提现次数、申请时间和到账时间。用户确认：每月 1—7 日集中审核打款，申请后预计 1—3 个工作日内处理。

页面据此说明“申请后预计 1—3 个工作日内完成审核并发起转账，非工作日顺延”；微信零钱需用户确认收款，实际到账以微信转账结果为准。此为人工运营时限，不代表系统新增自动审核或自动打款任务。

## 展示位置

- 我的收益：提现按钮下方常驻规则，不因提现窗口关闭或余额不足而隐藏。
- 提现申请弹窗：提交审核按钮前再次完整展示规则。
- 分销规则：推广流程前展示同一规则组件，并提供“查看可提现余额与申请进度”入口。

最低金额、费率、开放日期从后端读取；我的收益额外显示本人可提现余额。最低金额取后台配置与小程序既有 0.10 元底限中的较大值。单笔最高不超过可提现余额；待结算和退款抵扣部分不可提现。

现有服务没有每日固定申请次数上限，只拒绝同一用户重复提交待审核（status=0）或待财务付款（status=2）的申请，页面如实展示。没有新增次数限制或修改资金、资格、转账逻辑。

## 接口和发布

新增无需登录的 GET `/api/miniapp/referral/withdrawal-rules`，仅返回 `minAmount`、`feeRate`、`windowLabel`、`windowNotice`，不读取或返回用户余额、提现记录与银行卡资料。读取失败时展示重试入口，不编造金额或费率。

本轮未修改后台 Vue，沿用上一提交 e299c79a 中已生产构建的 public/admin。本轮后端接口需随 dev3 推送部署，小程序需重新上传提审；没有新增数据库字段或 SQL 补丁。
