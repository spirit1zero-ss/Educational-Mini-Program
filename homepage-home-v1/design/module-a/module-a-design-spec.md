# 模块 A 页面设计方案

## Product Design Brief

- 模块：A，一张图让孩子学科开窍。
- 目标：让用户先完成一个轻量、可信、儿童教育感的 A-F 测评，再进入结果页看到学科潜能解读和训练营引导。
- 视觉方向：延续首页的清爽小程序质感，白底、浅绿、浅金、轻阴影，少广告感；插图真实来自文档，不把页面切成整张图。
- 交互级别：设计阶段定义完整交互路径；代码阶段实现可选择、可跳转、可根据选项展示结果。
- 已确认视觉稿：
  - `design/module-a-assessment-mockup.png`
  - `design/module-a-result-mockup.png`

## 页面一：模块 A 测评页

- 路由建议：`pages/module-a-assessment/module-a-assessment`
- 用户目标：看懂题目，选择 A-F 中一个答案，进入结果页。

### 页面结构

1. 顶部安全区与标题
   - 自定义顶部留白避开微信胶囊按钮。
   - 标题：`一张图让孩子学科开窍`
   - 副标题：`启发灵感，让学习更加生动有趣`

2. 插图题目区
   - 使用文档插图 `miniprogram/assets/doc-images/ABC-02.jpeg`。
   - 图片上方用 WXML 文案说明题目：`请凭第一感觉，选择你认为图中红、蓝、黄分别对应的学科。`
   - 图片下方使用轻提示：`没有标准答案，按直觉选择即可。`

3. A-F 选项区
   - 6 个选项卡片，两列或单列自适应。
   - 小屏安卓优先单列；常规 iPhone 可两列但需要保证文字不挤。
   - 选中状态：左侧字母圆点变为绿色，卡片边框加深，背景轻绿色。

4. 底部操作区
   - 主按钮：`查看测评结果`
   - 未选择时 disabled，选择后高亮。
   - 底部 sticky，包含 `safe-area-inset-bottom`。

### A-F 选项内容

- A：红-小英 / 蓝-小数 / 黄-小语
- B：红-小英 / 蓝-小语 / 黄-小数
- C：红-小数 / 蓝-小语 / 黄-小英
- D：红-小数 / 蓝-小英 / 黄-小语
- E：红-小语 / 蓝-小数 / 黄-小英
- F：红-小语 / 蓝-小英 / 黄-小数

### 图片与 WXSS 分工

- 图片：
  - `ABC-02.jpeg`：题目主插图，来自文档。
- WXSS：
  - 页面背景、顶部标题区、提示标签、选项卡片、选中态、按钮、圆角、阴影、渐变和底部 sticky。
- 不做成图片：
  - A-F 选项、按钮、标题、说明文字、卡片装饰线。

## 页面二：模块 A 结果页

- 路由建议：`pages/module-a-result/module-a-result`
- 用户目标：看到自己的测评结果，理解优势和建议，并进入训练营或重新测评。

### 页面结构

1. 顶部安全区与返回
   - 顶部标题：`学科开窍测评结果`
   - 左侧保留返回入口，避开微信胶囊按钮。

2. 结果摘要卡
   - 标签：`你的结果`
   - 主标题根据 A-F 结果变化。
   - 显示所选组合，例如：`红-小英  蓝-小数  黄-小语`
   - 视觉：浅绿背景、白色卡片、轻阴影。

3. 学科对应区
   - 三个横向信息块：
     - 英语：自信与勇气
     - 数学：逻辑与思考
     - 语文：共情与浪漫
   - A 结果可完整展示三项；B-F 结果也保留三项基础说明，再突出建议学科。

4. 解读正文区
   - 标题：`潜能解读`
   - 正文根据结果 A-F 切换。
   - 文案保持温和鼓励，不做强营销。

5. 建议行动区
   - 主按钮：`了解 21 天线上特训营`
   - 次按钮：`重新测评`
   - 可以加轻量说明：`用 21 天，把孩子的开窍点变成真实学习成果。`

### 结果文案

- 正文：`你是一个内在有自信有勇气的人，你有英语学习的天赋！而且，你的行动力超强！建议：先从数学开始，用21天突破数学，可以大大激发出你内在力量，从而带动你的全面提升。`

- 正文：`你是一个情商高有自己独立思想的人，有很高的文科学习天赋。建议：从英语入手，快速提升学习自信心。`

#### F

- 标题：`表达力突出，适合继续放大优势`

### 图片与 WXSS 分工

- 图片：
  - 结果页暂不新增图片，避免广告感和模板感。
  - 如需视觉呼应，可复用 `ABC-02.jpeg` 的小缩略图，但默认不使用。
- WXSS：
  - 结果卡、学科能力块、标签、正文卡、行动按钮、背景层次、阴影和安全区。
- 不做成图片：
  - 结果内容、学科块、按钮、标签、卡片背景。

## 组件系统

### 建议组件

- `components/custom-nav`
  - 职责：顶部安全区、标题、返回按钮、胶囊避让。
  - Props：`title`、`showBack`
  - Events：`bind:back`

- `components/choice-card`
  - 职责：A-F 测评选项。
  - Props：`label`、`items`、`selected`
  - Events：`bind:select`

- `components/sticky-action`
  - 职责：底部主操作按钮与安全区。
  - Props：`text`、`disabled`、`secondaryText`
  - Events：`bind:primary`、`bind:secondary`

- `components/result-section`
  - 职责：结果页复用卡片区块。
  - Props：`title`、`tag`、`variant`
  - Slot：正文内容。

### 设计 Tokens

- 背景：`#F7FAF5`
- 卡片：`#FFFFFF`
- 主绿色：`#1F6B57`
- 浅绿色：`#EAF5EE`
- 金色强调：`#D8A640`
- 文字主色：`#1D2B26`
- 文字次色：`#7A8982`
- 细边框：`#E7EEE8`
- 圆角：卡片 `24rpx`，按钮 `999rpx`
- 阴影：轻阴影，不使用厚重发光

## 数据与交互

- 测评页状态：
  - `selectedType: '' | 'A' | 'B' | 'C' | 'D' | 'E' | 'F'`
  - `options: [{ type, label, subjects }]`
- 点击选项：
  - 更新 `selectedType`。
  - 主按钮变为可用。
- 点击 `查看测评结果`：
  - 跳转 `pages/module-a-result/module-a-result?type=A`
- 结果页状态：
  - 读取 `type`。
  - 从本地结果映射中展示标题、组合、正文和建议。
  - 如果没有 type，默认回退到 A 或提示重新测评。

## 适配检查

- iPhone：
  - 顶部内容用 `menuButtonBoundingClientRect` 或等效安全区计算，避免与微信胶囊按钮重叠。
  - 底部 sticky 使用 `env(safe-area-inset-bottom)`。
- 小屏安卓：
  - A-F 选项卡片允许单列排列。
  - 长句不放在窄按钮内，按钮文案保持短。
  - 插图高度限制，避免首屏只看到图片看不到选项。
- 微信胶囊按钮：
  - 自定义导航右侧不放关键按钮。
  - 标题区顶部 padding 不写死为普通 H5 数值。

## 与首页一致性

- 保持首页已确认的清爽白绿风格。
- 卡片、按钮、阴影、圆角节奏一致。
- 模块 A 的主按钮和首页 `去测评` 行为一致。
- 避免重新引入厚重渐变、过强插画、整页海报感。

## 下一步代码实现范围

1. 新建 `module-a-v1` 小程序页面文件或并入现有 `miniprogram/pages`。
2. 添加测评页与结果页 WXML/WXSS/JS/JSON。
3. 抽取可复用组件：`choice-card`、`sticky-action`，`custom-nav` 视首页现状决定是否共用。
4. 使用 `ABC-02.jpeg` 作为测评页主图。
5. 做一次 UI consistency review：和首页视觉、操作文案、底部/顶部安全区保持一致。
