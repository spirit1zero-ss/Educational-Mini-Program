# 模块 A UI Review

## Review Scope

- 页面族：模块 A 测评页与模块 A 结果页。
- 参考页面：`homepage-home-v1` 已确认的首页视觉方向。
- 设计目标：清爽、真实小程序、少广告感；文档插图做内容资产，卡片与按钮用 WXSS。

## Shared Skeleton

- 自定义顶部导航，避开微信胶囊按钮。
- 浅绿白背景。
- 内容卡片承载主要任务。
- 底部 sticky 主操作，包含安全区。
- 主按钮使用深绿色，次要/提示使用浅绿或浅金。

## Findings

### 1. 结构一致性

- 问题是否存在：未发现明显结构冲突。
- 为什么：测评页和结果页都遵循“顶部标题 -> 主要卡片 -> 次级内容 -> 底部操作”的页面骨架。
- 设计还是漂移：属于有意延续首页结构。
- 修法：无需调整。

### 2. 交互一致性

- 问题是否存在：未发现主要操作漂移。
- 为什么：测评页主按钮固定底部，结果页主按钮同样固定底部；重新测评作为次按钮，优先级清晰。
- 设计还是漂移：属于有意分级。
- 修法：训练营页面接入后，把 `onCamp` 从 toast 改为正式跳转。

### 3. 视觉一致性

- 问题是否存在：未发现明显视觉漂移。
- 为什么：颜色、圆角、轻阴影、白绿卡片和首页保持一致；没有把页面切成整张图。
- 设计还是漂移：属于正确复用。
- 修法：微信开发者工具中若实际图片裁切过高，可把测评页图片高度从 `338rpx` 微调到 `310rpx`。

### 4. 适配检查

- iPhone：`custom-nav` 根据 `getMenuButtonBoundingClientRect` 和状态栏计算顶部高度，底部组件使用 `env(safe-area-inset-bottom)`。
- 小屏安卓：测评选项在 `max-width: 340px` 下切换单列，标题字号下降，插图高度下降。
- 胶囊按钮：导航右侧留出胶囊宽度，关键操作不放在右上角。

## Assets Review

- 图片资产：只使用 `assets/images/module-a-characters.jpeg`，来自文档 `ABC-02.jpeg`。
- WXSS 实现：背景、卡片、按钮、圆角、阴影、选中态、底部栏、结果页能力块。
- 未使用切图：选项卡、结果卡、按钮、标签和正文都为 WXML/WXSS。
