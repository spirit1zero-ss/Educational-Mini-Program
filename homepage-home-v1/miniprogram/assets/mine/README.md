# Mine Page Assets

These assets support the `我的` tab design for the 21-day training camp and referral center.

## Main Visual

- `mine-hero-training-camp.png`
  - Use as the background image for the top `21天自主学习训练营` conversion card.
  - The left side intentionally has negative space for native WXML text and CTA overlays.
- `mine-hero-member-active.png`
  - Use as the paid-member state background for the top card.
  - It keeps the left side clear for native membership status, UID, and referral CTA text.
