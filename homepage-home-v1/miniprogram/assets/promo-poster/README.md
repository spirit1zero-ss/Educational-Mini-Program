# Promo Poster Assets

These assets support the member referral poster preview page.

- `promo-poster-bg.png`
  - No baked-in text or QR code.
  - Used as the vertical poster background. Native WXML overlays title, benefits, UID, and code.
- `miniapp-code-placeholder.png`
  - Temporary mini program code placeholder for frontend preview.
  - Replace with the real backend-generated mini program code image when `/api/miniapp/referral/poster` is connected.
